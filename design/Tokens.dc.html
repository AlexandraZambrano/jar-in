A jar’s pattern is fixed at creation and travels with it everywhere — chip, bar, donut segment, legend. Donut segments also get 3px bg-colour dividers. State (over cap / on track) always carries a ⚠ or ✓ glyph, never colour alone.

Sticker recipe

4px #FFF border (padding-box) · 1.5px ink ring · soft shadow 0 6px 14px /16% · radius 16 · optional 20% top gloss · decorative tilt ±0.6–1.5° seeded from index (never random per render).

Coach note recipe

Legal-pad paper, 2px ink border, hard 4px offset shadow (no blur), 5px accent spine, tape strip, radius 4, tilt −1.4°. Deliberately un-sticker-like — it’s “a real note pinned on top”. Caveat face → Hanken in Calm / CVD.

Accessibility modes

Calm Triggered by prefers-reduced-motion, prefers-contrast: more, or an in-app toggle. Tilt → 0. Gloss, page dot-grid, soft shadows removed; separation via a solid 2px ink ring. Type +1 step, body weight 500. Progress bars 12px with 2px border. Donut static, values labelled numerically. All motion ≤ 1 frame / opacity-only. Colour-blind safe Independent toggle, combinable with the others. Swaps to the Okabe–Ito jar set; every jar shows its fixed pattern + icon + text label + numeric %. Donut gets segment dividers and a leader-line legend. Status uses glyphs. Targets: fill-vs-neighbour ≥ 3:1, text ≥ 4.5:1. Dark Follows prefers-color-scheme + toggle. Warm eggplant base (not slate). Stickers become raised dark surfaces with a hue left-edge and a hue-tinted icon chip — fills are not flooded. Jar hues lightened ~10% to stop them vibrating. Coach note = aged paper.
Baseline for every mode: touch targets ≥ 44px, visible 2px focus ring at 2px offset, WCAG AA text (AAA for balances and the coach note), honour prefers-reduced-transparency (drop gloss + tape).
